# Support

SetadInfo is maintained through the public GitHub repository.

The synthetic public product lab is available at
`https://moroshani.github.io/setadinfo/`. It is for workflow evaluation, not
production support or real Setad data.

Use GitHub issues for:

- reproducible bugs;
- feature requests;
- documentation gaps;
- local development problems.

Do not open public issues for:

- production secrets;
- Rubika bot tokens or chat IDs;
- private server details;
- database dumps;
- security vulnerabilities.

Security reports should follow `SECURITY.md`.
